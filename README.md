# airbnb-Italy-powerbi-tableau
Airbnb Italy Power BI Dashboard
A 3-page Power BI report built on an Airbnb dataset for major Italian cities (Firenze, Milano, Napoli, Roma, Venezia). The dashboards provide (1) market overview of listings, reviews, ratings and price, (2) pricing insights including distribution, property-type pricing and price vs rating, and (3) host insights comparing Host vs Superhost performance and trends over time. Includes interactive slicers for city, neighbourhood, property type, season, and price bins to support fast drill-downs and comparisons.
